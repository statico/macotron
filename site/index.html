Macotron does everything.

Tile windows, bind hotkeys, drive the menu bar, read sensors, capture the screen, talk to models. From small JavaScript files that you, or your coding agent, can read and change.

Download for macOS Source on GitHub

brew install statico/tap/macotron

Free and open source. Built with Swift and QuickJS.

Beta. Macotron goes 1.0 when I, the author, consider it stable. Until then, expect things to move around.

  1. Your own menu bar

    Two lines, stoplight colors: is prod current, and how many commits behind. About thirty lines of JavaScript.

  2. Quick launcher

    Files, apps, math and commands, fuzzy-ranked as you type.

  3. Window management

    Hotkeys, drag-to-snap and a grid for the focused window.

  4. Meeting bar

    The next meeting and its join link in the menu bar, and a full-screen reminder with a QR code when it starts.

  5. Now Playing

    Track, artist and cover art from whatever is playing. Here, SomaFM.

  6. CPU, memory and audio

    Live CPU, GPU and memory in the menu bar, with the detail one click away.

  7. Community plugins

    Browse plugins people publish on GitHub, add one, and it's in the launcher. Yes, chess.

Plugins

The catalog ships 74 built-in plugins. First launch copies the ones you pick into plugins/. Macotron writes an AGENTS.md next to them so a coding agent already knows the API. Open a file in the finder to read the script this site ships.
