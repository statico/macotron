Built-in plugins

Macotron ships with 74 plugins. None run until you add them. Add them in the first-run wizard, or later from Settings → Plugins → Catalog. Each one is a single JavaScript file that you can read, change, or copy.

Featured plugins are highlighted in the catalog. A permission in the list means the plugin declares it, and Macotron asks for it when you add the plugin. See Permissions. Most plugins add launcher commands; the source for all of them is in Examples/plugins.

Launcher and search

  • Calculator (calculator.js, Featured): do math and convert units in the launcher. See Launcher.
  • File Search (file-search.js, Featured): find files and folders as you type, from Macotron's own index. See File search.
  • Contacts Search (contacts.js): search your contacts.
  • Notes Search (notes.js, Featured): search Apple Notes and open one.
  • System Settings Search (system-settings.js, Featured): open System Settings panes.
  • Web Search (web-search.js): search Google, Wikipedia, Maps, YouTube, or GitHub, or look up a word in Dictionary.
  • Shortcuts (shortcuts.js): run your shortcuts from Shortcuts.app.
  • Emoji Picker (emoji.js): search emoji by name, with the ones you use most at the top.
  • Lock Screen Command (lock-screen.js, Featured): lock this Mac.

Windows and spaces

  • Window Controls (windows.js, Featured, Accessibility): tile with hotkeys, snap by dragging to an edge, switch windows by name. See Window management.
  • Window Quick Grid (window-grid.js, Featured, Accessibility): place the focused window by dragging across a grid.
  • Window Switcher (window-switcher.js, Accessibility, Input Monitoring): hold Option and press Tab to flip through windows.
  • Window Layout Save & Restore (layouts.js, Accessibility): save the window layout and restore it later.
  • Gesture Examples (gestures.js, Input Monitoring, Accessibility): swipe three fingers left or right to tile the focused window.
  • Spaces Controls (spaces.js, Accessibility): switch to the next Mission Control desktop.

Keyboard and input

  • Hyper Key (hyper.js): use Caps Lock as Command, Shift, Control, and Option together. See Hotkeys.
  • HID (USB) Example (hid.js): list keyboards, mice, and other input devices.
  • USB Watcher Example (usb.js): announce when a USB device is plugged in, and list attached devices.

Clipboard and text

  • Clipboard History (clipboard-history.js, Featured): search recent clipboard items and paste one. See Clipboard.
  • Clipboard Images (clipboard-image.js): paste the latest image from clipboard history.
  • Plain Paste (plain-paste.js): paste as plain text when you press Command-V.
  • Text Snippets (snippets.js, Featured): expand short abbreviations into longer text. See Snippets.
  • Markdown Preview (markdown.js): preview Markdown from the clipboard in a panel.
  • Date and Time Stamps (datetime.js): copy the current date and time in ISO-8601 format.
  • Dev Utils (devutils.js): copy a UUID, Unix time, Base64 text, or a decoded JWT.
  • Lorem Ipsum Generator (lorem.js): copy placeholder text.
  • Regex Workbench (regex.js): test a regular expression against sample text.
  • Share Commands (share.js): share clipboard text or a file with the share sheet or AirDrop.

Screen and display

See Screen tools.

  • OCR (ocr.js, Screen Recording): drag a box on screen and copy the text inside it.
  • QR Code Tools (qr.js, Screen Recording, Camera): scan a QR code from the screen or camera, or show one for text.
  • Color Picker (color-picker.js): click a pixel and copy its color.
  • Screenshot Rename (screenshot-rename.js, Screen Recording): rename the latest screenshot from the text in it.
  • Color Blindness Simulator (color-blindness.js, Screen Recording): show the screen the way a color-blind viewer sees it.
  • Screen Effects (screen-effects.js): red tint, extra dark, invert, CRT overlay, Night Shift, True Tone, and grayscale.
  • Brightness Commands (brightness.js): dim or brighten the display, and turn XDR on or off.
  • Appearance Toggle (appearance.js): switch between light and dark appearance.
  • Presenter Mode (present-mode.js): hide desktop icons while you present or share your screen.

Menu bar meters

See Menu bar.

  • CPU, GPU and Memory Graph (cpu-graph.js): CPU core, GPU, and memory gauges.
  • System Metrics Example (system-metrics.js): CPU and GPU usage.
  • Battery Meter (battery.js): charge level and time remaining.
  • Bluetooth Device Levels (bluetooth.js): battery levels for paired Bluetooth and USB input devices.
  • Network Stats (network-path.js): network speed and ping.
  • Storage (disk-usage.js): see how much space the folders in your home folder use.
  • Time Machine Progress (time-machine.js): backup progress.
  • Fan Control Menu (fan.js, Background Helper): fan speed, and a minimum speed. See Fan control.
  • Weather (weather.js, Featured): the current weather.
  • World Clock (world-clock.js): the time in several cities.
  • Park Webcam (park-webcam.js): the Roosevelt Arch at Yellowstone, live.
  • Icon Rainbow Example (icon-rainbow.js): cycle the Macotron icon through rainbow colors.

Calendar and time

See Meetings and calendar.

  • Meetings (meetings.js, Featured, Calendars): the next event in the menu bar, today's agenda, one-click join, and a full-screen overlay when a meeting starts.
  • Mini Calendar (mini-calendar.js, Featured): today's date in the menu bar, with the month in its menu.
  • Reminders (reminders.js): your next reminder in the menu bar.
  • Upcoming Events Example (calendar.js): show your upcoming calendar events.
  • Pomodoro Timer (pomodoro.js): a 25-minute focus timer in the menu bar.

Audio and media

  • Audio Menu Bar Widgets (audio.js): switch speakers and mute from the menu bar; ⌃⌥A cycles the output device.
  • Mic Mute (mic-mute.js): mute or unmute the microphone from the menu bar.
  • Now Playing (now-playing.js): the current track in the menu bar, with play, pause, and skip.
  • Headphone Pause (headphone-pause.js): pause playback when you unplug headphones.
  • Camera & Mic Tools (record.js, Microphone, Camera): record the microphone, or preview and snapshot the camera.
  • Apple TV Controls (apple-tv.js): find Apple TVs on your network and open a remote.

System and power

  • Stay Awake Toggle (power.js): keep this Mac awake and unlocked from the menu bar.
  • Wi-Fi Toggles (wifi.js): turn Wi-Fi, Bluetooth, and AirDrop on or off from the menu bar.
  • Eject Disks from Menu Bar (eject.js): eject disks, and empty the Trash.
  • Security Checklist Example (security-checklist.js): check FileVault, the firewall, System Integrity Protection, and app updates.
  • Profiles Example (profiles.js): light appearance on your home Wi-Fi, dark at work.
  • Idle Example (idle.js): show how long this Mac has been idle, and notify when it goes idle or wakes.
  • Frontmost App Example (focus-idle.js): show the app in front and the last app you switched to.
  • Home Scenes (homekit.js): run Home scenes from the menu bar. Each scene is a shortcut in the Shortcuts folder named Home.

Files

  • Batch Rename Downloads (batch-rename.js): add today's date to the start of files you downloaded today.
  • HEIC to JPEG (heic-to-jpeg.js): convert HEIC photos in Downloads to JPEG.

Links and AI

  • Browser Picker (browser-picker.js): route links by host, then ask or use one browser for everything else. See Browser picker.
  • AI Chat Window (ai-chat.js): chat with Apple Intelligence, Claude, or Gemini. See AI.
  • Translate Selected Text (translate.js, Accessibility): translate the selected text with Apple Intelligence.
  • Screen Summary Example (screen-ai-summary.js, Screen Recording): drag a box on screen and ask Claude what is in it.
