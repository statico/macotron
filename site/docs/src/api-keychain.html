macotron.keychain

Store API keys, tokens, and other secrets in the macOS login Keychain, so they stay out of plugin source and settings files.

let token = macotron.keychain.get("github-token");
if (!token) {
  token = prompt("GitHub token");
  if (token) macotron.keychain.set("github-token", token);
}

Secrets

Each value is a generic password item under the service io.statico.macotron, with your key as the account name. You can see and delete the items in Keychain Access.

get(key: string): string | null

The stored value, or null when there is none.

set(key: string, value: string): void

Stores value, replacing any value already stored under key. A Keychain error is written to the log and not thrown.

delete(key: string): void

Removes the item. Deleting a key that does not exist does nothing.

has(key: string): boolean

Whether a value is stored under key.

Sharing and scope

Keys are not separate per plugin. Every plugin reads and writes the same set, so keychain.get("anthropic-api-key") returns the same key to every plugin. Use this to share one key, and pick distinct names when you do not want to share.

A password option declared in macotron.plugin() is stored in the same place, under the account macotron.plugin.<file>.<option>. For one plugin's own secret, a password option is usually simpler: the user enters it in Settings and the plugin gets the value from macotron.plugin().

Keys that start with macotron.plugin.hash. are reserved for Macotron. get() returns null, has() returns false, and set() and delete() do nothing for them.
