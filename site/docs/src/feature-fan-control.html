Fan control

The Fan Control Menu plugin shows fan speed in the menu bar and can hold the fans at a minimum speed. Reading the speed needs nothing. Setting a minimum needs the Macotron background helper.

The fan menu

fan.js puts a fan icon in the menu bar. The icon is filled while a minimum speed is held. It refreshes every two seconds.

  • Left-click the icon to turn the minimum on or off. The Menu bar click sets setting picks 50% or 100% (the default).
  • Right-click or Control-click for the menu. It shows the speed of each fan in RPM, then 50%, 100%, and System default. A check mark shows the current choice.

The launcher commands Toggle Fan 50% and Toggle Fan 100% do the same thing. Run one again to give control back to macOS.

On a Mac with no fans, such as a MacBook Air, the menu says No fans on this Mac.

What a minimum speed means

The setting is a floor. The fans do not run slower than the speed you chose, measured between the fan's own lowest and highest speed. Above that, macOS still controls them. When the Mac gets too hot, the helper gives the fans back to macOS, so a floor never holds a hot machine down.

The plugin remembers your choice and puts it back after a plugin reload or a restart of Macotron.

When Macotron quits or crashes, the helper gives the fans back to macOS at once. A Mac is never left with its fans pinned.

The background helper

Changing fan speed needs root access, which Macotron itself does not have. The background helper is a small system service, inside the Macotron app, that does only this job. Macotron talks to it while it runs.

To install it:

  1. Open Settings → Plugins → Fan Control Menu, or Settings → Permissions. Both show a Background Helper row.
  2. Click Install….
  3. macOS adds the helper to System Settings → General → Login Items & Extensions, switched off. Switch it on there. macOS asks for an administrator password.

Until the helper is installed, the plugin page shows an orange Speed control check that says it can read speed only, and the fan menu has an Install background helper… row.

After the helper is installed, its row shows an Installed menu:

  • Reinstall… removes the helper and installs the copy in the current app. Use it after you update Macotron if fan control stops working.
  • Remove uninstalls the helper. Speed still shows; setting a minimum does not work.

If installation fails with a message that Macotron was replaced on disk, quit and reopen Macotron, then click Install… again.
