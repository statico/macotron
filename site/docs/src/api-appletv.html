macotron.appletv

Find Apple TVs and other AirPlay devices on the local network. The send call is in place for remote keys, but it cannot control a TV yet.

const tvs = await macotron.appletv.list();
macotron.notify.toast("Apple TV", tvs.map((t) => t.name).join(", ") || "None found");

Finding devices

list(): Promise<Array<{ id, name, host, port, type }>>

Browses Bonjour for _companion-link._tcp and _airplay._tcp for 1.5 seconds and resolves with what it finds. id is "host:port", type is the service type, and name is the name set on the device.

Macotron reuses a result for 30 seconds, so repeated calls return at once. An empty result is not reused.

Every device that offers either service shows up, so the list can include AirPlay speakers, smart TVs, and Macs as well as Apple TVs. One Apple TV usually appears twice, once per service, with a different port in each id. Group rows by host or name for a picker. macOS asks for Local Network permission the first time Macotron browses.

Remote keys

send(id: string, command: "up" | "down" | "left" | "right" | "select" | "menu" | "home" | "play" | "pause" | "playpause"): Promise<{ ok: boolean; error?: string }>

Meant to press a key on the Apple TV's remote. Controlling an Apple TV needs Companion pairing, which Macotron does not implement yet, so this resolves { ok: false, error: "not paired" } for a device from list(). For an id that is not in the list, it resolves { ok: false, error: "No Apple TV" }.
