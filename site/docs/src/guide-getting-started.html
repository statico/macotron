Getting started

Macotron is a menu bar app that runs small JavaScript plugins. This page takes you from the download to your first working hotkey.

Install

Pick one:

  • Download the DMG, open it, and drag Macotron into Applications.
  • Run brew install statico/tap/macotron.

Either way, Macotron updates itself after that. See Updates.

Macotron runs on macOS 15 Sequoia and later. Apple Intelligence features (the on-device chat model and the plugin scanner) and the Liquid Glass panels need macOS 26 Tahoe.

First launch

The first launch opens a short setup window. It has five steps.

  1. Welcome. A one-line summary of what Macotron is.
  2. Plugins Folder. Select Choose Folder… and pick a folder for your plugins and settings. This folder is your workdir. ~/Macotron is a good choice.
  3. Add Some Plugins. Add built-in plugins from the catalog. Select Add on a row, or Details… to read what a plugin does and which permissions it needs. I Feel Lucky, Add Everything! adds all of them. You can skip this step and add plugins later.
  4. Grant Permissions. One row for each macOS permission that Macotron and your plugins need. Select the button on each row. The list updates by itself as you approve each one.
  5. You're All Set! Select Open Macotron.

What is in the workdir

Macotron fills the folder you picked with this layout:

~/Macotron/
  plugins/        your plugins, one .js file each
  settings.json   launcher hotkey, UI preferences, plugin options
  data/           what plugins save with localStorage
  backups/        a copy of each plugin you delete
  README.md       yours to edit; written once
  AGENTS.md       written by Macotron for coding agents
  CLAUDE.md       points at AGENTS.md
  .cache/         bytecode cache and the typed API file

When Apple's developer tools are installed, Macotron also runs git init in the folder. It never makes commits itself. To move the workdir later, open Settings → General → Plugins Folder and select Change….

Try it

  • Press ⌥Space to open the launcher. Type to search apps and the commands your plugins added.
  • Look at the new items in the menu bar. Plugins such as Mini Calendar and Weather put their own items next to the Macotron icon.
  • Open Settings… from the Macotron menu. The Plugins tab lists every plugin, its hotkeys, its commands, and its options.

Add more plugins

Open Settings → Plugins and select Catalog. The Built-In tab lists every plugin that ships with Macotron. The Community tab lists plugins that other people publish on GitHub; see Community plugins. Built-in plugins has a one-line summary of each.

Grant permissions

Macotron asks for a permission only when it, or an enabled plugin, needs it. Input Monitoring, Accessibility, and Automation are always on the list. Others, such as Screen Recording or Calendars, show up when you add a plugin that declares them.

A missing permission puts a red dot on the menu bar icon and a Permissions needed row at the top of the menu. Settings → Permissions lists each one with a Grant… button. Permissions explains each one.

Write your own

Open the workdir in a coding agent such as Claude Code or Codex and describe what you want. The agent reads AGENTS.md and writes the plugin. See Coding agents and Writing plugins.
