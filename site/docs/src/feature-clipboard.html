Clipboard

Three built-in plugins work with the clipboard. Clipboard History lets you find and reuse recent copies. Clipboard Images brings back the last image. Plain Paste removes formatting when you press Command-V.

Clipboard History

Turn on Clipboard History and Macotron starts to record what you copy. Each copy becomes a launcher row. Type part of the text to find it, then press Return. Images show as rows named "Image".

Run the Clipboard History command for a panel that lists every entry with its time and a filter field. Click an entry to use it.

Picking an entry puts it back on the clipboard. It does not paste it. Press ⌘V in the app where you want it.

Macotron keeps:

  • The newest 50 entries from the last 24 hours.
  • Text and images.
  • In memory only. History is gone when Macotron quits.

Password managers mark the secrets they copy. Macotron never records a copy with those marks (org.nspasteboard.ConcealedType or TransientType).

Clipboard Images

The Clipboard Images command finds the newest image in clipboard history and puts it back on the clipboard. Use it when you copied an image, then copied text over it. It uses the same history, so it only finds images copied after a plugin started recording.

Plain Paste

With Plain Paste on, ⌘V in any app pastes only the plain text. Fonts, colors, and links are dropped. The plugin has one setting, Paste as plain text, which is on by default. Turn it off in Settings → Plugins → Plain Paste, or disable the plugin.

Plain Paste needs Accessibility. Without it, Command-V keeps the formatting. See Permissions.

Related plugins

  • Markdown Preview: Markdown from Clipboard renders the clipboard as Markdown in a panel.
  • Dev Utils: Encode Base64 and Decode JWT read the clipboard.
  • Share Commands: share clipboard text with the share sheet or AirDrop.

Use it in a plugin

macotron.on("clipboard:changed", () => {
  const text = macotron.clipboard.text();
  if (text.startsWith("http")) console.log("clip: copied a link");
});
