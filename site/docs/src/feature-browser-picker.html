Browser picker

The Browser Picker plugin makes Macotron your default browser, then hands each link to a real browser: by rules you write for hosts and paths, optionally into a Chrome profile, and for everything else either one browser or a panel that asks.

How it works

When browser-picker.js loads, it asks macOS to make Macotron the handler for http and https links. macOS asks you to confirm the change. From then on, a link you click in Mail, Slack, or any other app goes to Macotron, and the plugin passes it on.

For each link, the plugin checks your rules first. If no rule matches, it uses the Unmatched links setting. Ask every time (the default) shows a small Open Link panel with one button for each browser. Click one, or click elsewhere to close the panel.

The plugin knows Chrome, Chrome Beta, Chrome Dev, Chrome Canary, Safari, Firefox, Edge, Arc, and Brave.

Rules

Write one rule per line in the Rules setting: a pattern, a space, and a browser. The first line that matches a link wins.

youtube.com chrome:Default
youtu.be safari
github.com/acme chrome:Profile 1
/^github\./i firefox
* chrome:Profile 1
  • A plain host matches that host and its subdomains, so youtube.com also matches www.youtube.com, but not badyoutube.com.
  • A host and a path, such as github.com/acme, also needs the link's path to start with that path, whole segments only and ignoring case. It matches /Acme/repo but not /acme-evil.
  • * matches every link. Put it last to choose a browser or profile for everything your other rules miss.
  • A pattern written as /pattern/flags is a JavaScript regular expression, tested against the link's host.
  • The browser is its name, such as chrome, Chrome Beta, or brave. Case and spaces do not matter. For any other app, use its bundle ID, such as com.vivaldi.Vivaldi.
  • For Chrome, Edge, and Brave, add a colon and a profile: chrome:Profile 1. The profile runs to the end of the line. Use the profile's folder name, which chrome://version shows at the end of Profile Path, or its name if no other profile has the same name. A name means reading the browser's profile list, which macOS may ask you to allow. A folder name never does.

A rule the plugin can't use is listed in the plugin's checks in Settings. A rule with a bad pattern or an unknown browser is skipped. A rule with a profile that can't be found opens links without a profile. A link whose browser isn't installed goes to the Unmatched links setting.

The default rules send YouTube links to Safari.

Open a URL from the launcher

The launcher command Open URL takes a URL and an optional browser. Without a browser, it follows the Unmatched links setting. A URL with no scheme gets https://.

Turning it off

If you disable or delete Browser Picker, macOS still sends links to Macotron. A link that no plugin handles goes to the app that would have opened it if Macotron were not installed, so links keep working. To stop the round trip, choose a different default browser in System Settings → Desktop & Dock → Default web browser.

Write your own routing

Browser Picker is a short plugin built on macotron.url. The core is a few lines:

macotron.url.setDefaultHandler("https");
macotron.url.on("https", "zoom.us", (event) => {
  macotron.url.open(event.url, "us.zoom.xos");
});

A macotron:// link can come from any app or web page. Macotron asks you to allow each one before a plugin sees it. See Security.
