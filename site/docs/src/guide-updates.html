Updates

Macotron checks for new versions by itself and asks before it installs one. Plugins never update by themselves; you approve each one.

App updates

By default Macotron checks once a day. When it finds a new version, the Macotron menu shows Update to version... in place of Check for Updates.... Select it to see the release notes and install. Macotron does not install anything until you say yes.

To check right now, select Check for Updates... in the Macotron menu.

This works the same whether you installed from the DMG or with brew install statico/tap/macotron.

How often to check

Open Settings → General → Updates and pick one:

SettingWhat it does
DailyChecks once a day. The default.
WeeklyChecks once a week.
NeverNo automatic checks. Check for Updates... still works.

The Check Now button next to the setting does the same as the menu item.

Signed updates

Every update carries a signature. Macotron installs it only when the signature matches the public key inside the copy you already have. A hijacked download or a tampered feed cannot install anything.

Built-in plugin updates

A new version of Macotron can ship newer copies of the built-in plugins. Your installed copies do not change on their own. When the app has a newer copy than the one in your plugins/ folder:

  • The plugin shows an update badge in Settings → Plugins, with Update… on its page.
  • The Macotron menu shows a row such as 2 plugin updates available.
  • Update All in Settings → Plugins updates every built-in plugin at once.

Updating a built-in plugin replaces your file with the copy that ships with Macotron. Any changes you made to that file are lost. To keep your changes, copy the plugin to a new file name first.

Community plugin updates

Community plugins update one at a time, through the same review sheet as a first install. See Community plugins.
